## 📝 Projektbeschreibung

Das Programm **Logarithmusdarstellung** berechnet für die Zahlen von 80 bis 1 den dekadischen Logarithmus (`log10`) und stellt das Ergebnis grafisch mit Sternen (`*`) in der Konsole dar.

### Funktionen:
- **Ausgabe der Zahlen:** Zahlen von 80 bis 1 werden ausgegeben.
- **Logarithmusberechnung:** Verwendung von `Math.log10()`.
- **Sternendarstellung:** Der Logarithmuswert wird mit Sternen visualisiert.
- **Konsolenausgabe:** Textbasierte Darstellung der berechneten Werte.
