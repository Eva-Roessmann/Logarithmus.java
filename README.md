# Logarithmusdarstellung mit Sternen

## Beschreibung

Dieses Programm stellt die logarithmische Funktion zur Basis 10 für die Zahlen von 80 bis 1 dar.

Die Ausgabe erfolgt in umgekehrter Reihenfolge.

Zur grafischen Darstellung werden Sterne verwendet. Die Anzahl der Sterne wird aus dem berechneten Logarithmuswert bestimmt.

## Verwendete Konzepte

- Schleifen (for)
- Mathematische Funktionen
- Verschachtelte Schleifen
- Ausgabe auf der Konsole
